# Mahek Ara Bangi

I build AI tools and the operations around them: reliable data, clear handoffs, and decisions that can be checked. I’m an AI engineering graduate working in program and people operations at Sambhav Foundation.

## Current work

- **[Context Relay](https://github.com/mahekara28/context-relay)** — a local CLI, workbench, and MCP handoff for carrying reviewed task context between coding agents. [See the project](https://mahekara28.github.io/context-relay/).
- **[Inference provider evaluation](https://mahekara.vercel.app/blog/inference-provider-evaluation)** — a workload-first comparison of documented deployment paths for Simplismart, Modal, and Baseten. It includes a [blank run sheet](https://mahekara.vercel.app/downloads/inference-run-sheet.csv) for a matched trial; it does not claim measured performance that has not been tested.
- **[Build, Buy or Borrow](https://github.com/mahekara28/build-buy-borrow)** — a local decision tool for comparing staffing approaches against time, budget, and capacity constraints using fictional scenarios.
